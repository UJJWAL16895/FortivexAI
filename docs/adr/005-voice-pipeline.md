# ADR 005 · Measure modular speech before adopting Live audio

Accepted for evaluation. Endpointing, transcription, retrieval, generation and synthesis have distinct latency and quality failures. A pipeline exposes stage timings, cancellation boundaries and replaceable speech adapters. Compare against Gemini Live on identical bilingual scripts. Migration depends on measured benefit, tool compatibility and free-tier access. edge-tts is an unofficial demo-only integration.
