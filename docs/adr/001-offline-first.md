# ADR 001 · Offline-first provider boundaries

Accepted for design. Live model listing succeeded while a generation probe failed in STEP-000. The user needs a credible interview demo during quota or network loss. Use deterministic, clearly labelled mocks behind the same contracts as live adapters. Each adapter exposes failures to the coordinator. Preserve demo state across fallback. The cost is contract testing for both paths. Exercise failover and shared budgets at P2.
