# Definition of done

A phase closes after acceptance tests, lint, formatting, strict core typing, a secret scan of staged and working files, a manual check, diff review, real output in a report, learning log, changelog and a Conventional Commit. Verify each Make target through its Windows/Python equivalent. A failed mandatory check keeps the gate open.

P1 and the voice-plus-booking/CRM release each require a clean-checkout demo with a named Git tag. Project completion additionally requires the full recorded hero flow, successful mock and eligible live runs, a sourced business and operational case, complete architecture and interview materials, a reproducible setup, and honest measurement limitations. A passing health check proves only the foundation.
