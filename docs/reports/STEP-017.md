# STEP-017 · Download a saved report

Before, a completed report was readable in the console. Now the same validated derived fields can be downloaded as Markdown. No raw transcript, contact key or PDF service is used.

## Quiz

1. **Where is the file built?** In the browser.
2. **What is the input?** The validated saved report already displayed.
3. **What can be edited after export?** The downloaded Markdown.
4. **What does the export omit?** Raw transcript and contact identifiers.
5. **Does export send a follow-up?** No. The operator reviews the draft.
